# 🗑 «Скинуть весь мусор» — инструкция

Кнопка в главном меню: **🗑 Скинуть весь мусор**. Это «корзина», куда
можно накидать что угодно одним потоком, а бот потом всё это **прочитает**,
комбинируя уже имеющиеся функции, и ответит на твой вопрос.

## Как пользоваться
1. Жми **🗑 Скинуть весь мусор** — бот переходит в режим сбора.
2. Кидай подряд что угодно: ссылки, видео, GIF, документы (PDF/DOCX/XLSX/PPTX),
   фото, голосовые, аудио, обычный текст. Бот ничего не отвечает — только
   складывает в кучу и показывает счётчик.
3. Последнее **текстовое** сообщение считается «вопросом» (что сделать с
   материалами).
4. Жми **📤 Отправить** — бот читает всю корзину и отвечает на вопрос.
   Корзина очищается, режим сбора остаётся (можно копить новую пачку).
5. Жми **✖️ Закрыть** — финальный ответ (если в корзине что-то есть) и
   возврат в обычный режим. **🧹 Очистить** — просто опустошить корзину.

## Правило чтения (комбинирование функций)
Каждый элемент читается лучшим доступным способом, всё объединяется в один
контекст для LLM:

| Что кинули | Как читается |
|------------|--------------|
| 🔗 Ссылка | markitdown (YouTube/Vimeo транскрипт, PDF, статьи) → Firecrawl scrape → Tavily |
| 🎬 **Видео** | **скриншот ключевого кадра (cv2) → Groq Vision / OCR**, плюс **markitdown** по файлу; для видео-ссылок можно подключить **Apify**-актор для скрейпинга |
| 🎞 GIF/анимация | как видео |
| 📄 Документ | markitdown → markdown (PDF, DOCX, XLSX, PPTX, …) |
| 🖼 Фото | Groq Vision (описание + текст) → OCR (pytesseract) |
| 🎙 Голос / 🎵 Аудио | Groq Whisper (расшифровка) |
| 📝 Текст | как есть |

Каждый ридер «мягкий»: если что-то не прочиталось, бот пишет короткую
пометку и идёт дальше — остальная пачка всё равно обрабатывается.

## Где в коде
- Логика корзины: `bot/addons/dump/store.py`
- Чтение материалов: `bot/addons/dump/readers.py` (переиспользует
  `wizard._run_markitdown`, `groq_helpers.transcribe_audio_with_groq` /
  `describe_image_with_groq`, `external_tools.firecrawl_scrape` /
  `tavily_search` / `apify_run_actor`, `pytesseract`, `cv2`)
- UI/хендлеры (на `wizard_router`, состояние `DumpStates.collecting`):
  `bot/wizard.py` (секция «🗑 Скинуть весь мусор»)
