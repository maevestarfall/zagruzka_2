# 🧩 20 API-слотов, остаток, приват режим и оплата

Инструкция по возможностям, добавленным в v17.43–v17.45. Всё настраивается
**изнутри Telegram через кнопки** — править код не нужно.

---

## 1. 20 API-слотов (мозг с авто-переключением)

**Путь:** `/setup → ⚙️ Настройки → 🧠 Авто мозг → 🧩 20 API-слотов`
(также `/setup → ⚙️ Другое`).

Каждый слот — отдельный OpenAI-совместимый эндпоинт со своим ключом:

- **🔑 API-ключ**, **🌐 URL**, **🤖 Модель 1/2/3**, **🎟 Бюджет токенов**.
- **📝 cURL / код (авто-разбор)** — вставь curl, бот сам вытащит ключ, URL и
  модель.
- **💰 Остаток с провайдера** — см. раздел 2.

**Авто-переключение:** когда у активного слота кончается ключ/бюджет/баланс
или приходит ошибка API — чат сам переходит на следующий настроенный слот.
Перед переключением состояние (история + счётчики + позиция цепочки)
сохраняется на диск `/data/state.json` и сверяется (до 3 повторов), и только
потом происходит переключение — чтобы ничего не потерялось.

**🧩 Во все 20 слотов:** экран с URL + 3 модели + «Залить во все 20 слотов».
Заливает URL и модели во все слоты; API-ключи не трогаются (у каждого слота
свой ключ — на этом и держится переключение). По умолчанию активна модель 1.

**Селектор модели сверху:** показывается столько кнопок, сколько моделей
заполнено (только model1 → 1 кнопка; добавил model3 → появилась 3-я). Выбор
переключает активную модель глобально.

## 2. Остаток токенов / баланса (iyh.app и др.)

Два независимых механизма, оба учитываются при авто-переключении:

1. **Ручной бюджет** (🎟) — вводишь число, бот вычитает потраченные токены.
2. **Реальный остаток с провайдера** (💰) — бот сам запрашивает баланс:
   - кнопка **💰 URL остатка** — вставь точный адрес (например дашборд
     iyh.app или `https://api.x/v1/credits`). Можно оставить пусто — бот сам
     переберёт стандартные адреса (`/auth/key`, `/credits`, `/balance`,
     `/user/balance`) от URL слота;
   - кнопка **🔄 Запросить остаток** — делает запрос и показывает остаток в
     карточке слота. Понимает форматы OpenRouter (`/auth/key`, `/credits`),
     OpenAI (`credit_grants`) и общий `balance`/`credits`.
   - Если остаток ≤ 0 — слот выпадает из цепочки переключения.

## 3. Массовый импорт в 20 слотов

Три способа заполнить слоты пачкой:

1. **📥 Массовый импорт (все 20 разом)** — кнопка в меню 20 слотов. Форматы:
   - JSON-объект: `{"bulk":{...}, "slots":{"1":{...}, "2":{...}}}`
   - JSON-массив (позиция = номер слота): `[{"api_key":"sk-1"}, {"api_key":"sk-2"}]`
   - построчно: `1 | key=sk-...; url=https://api.x/v1; model1=gpt 5.5; budget=100000`

2. **🔌 API** (старая кнопка масс-импорта в настройках) — теперь умеет писать в
   слоты. Таргеты:
   - `slot1`…`slot20` с полями `api`, `url`, `model1/2/3`, `budget`, `curl`, `balance`
   - `slotsall` — URL + model1/2/3 во все 20 разом
   - пример: `slotsall:url:https://api.x/v1;slotsall:model1:claude$$$slot1:api:sk-aaa$$$slot2:api:sk-bbb;slot2:budget:100000`

## 4. 🔒 Приват режим (тонкий доступ для гостей)

**Путь:** `/setup → ⚙️ Настройки → ⛔ Доступ → 🔒 Приват режим`.

Когда **ВКЛ** — владелец видит и может всё, а гостям доступно только то, что
отмечено зелёной ✅. По умолчанию всё ВЫКЛ.

- **🧩 Функции** — что гость может *использовать* (кодинг, анализ, гитхаб,
  терминал, фото/видео, helpzavr, красивый текст, монтажёр, скинуть мусор,
  дебаты, OSINT, почта, память, голос, справочник промтов). Тап → ✅/⚪.
- **👁 Что они видят** — что гость *видит* в меню (тот же список, независимо
  от «Функций»).

**Как это реально применяется (с этой версии):**
- **USE** — внешняя middleware `bot.feature_gate.build_feature_use_gate_middleware`
  стоит сразу после платного гейта. Для гостя она определяет, какую функцию
  открывает его нажатие/команда (реестр `FEATURE_CALLBACK_PREFIXES` /
  `FEATURE_COMMANDS`), и блокирует с алертом, если у функции не стоит ✅ в
  «Функциях». Владелец/со-владельцы проходят всегда; обычный чат и админ-экраны
  не трогаются.
- **SEE** — `bot.feature_gate.filter_menu_rows` убирает из главного меню и из
  «Настроек» кнопки тех функций, у которых не стоит ✅ в «Что они видят».
- Когда приват-режим **ВЫКЛ** — оба слоя бездействуют, бот работает как раньше.

## 5. 💰 Оплата

**Путь:** `… → 🔒 Приват режим → 💰 Оплата`.

- Три способа, каждый с тогглом ВКЛ/ВЫКЛ: **💳 Карта** (РФ/Mastercard),
  **⭐ Звёзды Telegram**, **🪙 Крипта**. Выключенный способ гостю **даже не
  предлагается**.
- **✏️ Реквизиты** для карты и крипты (номер карты / адрес кошелька + сеть).
- **💵 Цена** — `$X = 1 слот` (по умолчанию $10).
- **🎟 Токенов на 1 слот** — сколько токенов даёт один оплаченный слот
  (по умолчанию 1 000 000). Из цены и этого числа считается стоимость токена.
- **Требовать оплату при входе** — тоггл.
- **Баланс (потокенно):** баланс гостя списывается **по мере расхода токенов**
  (`usd_per_slot / tokens_per_slot` за токен) на каждом ответе модели. Когда
  баланс доходит до 0 — гейт показывает «лимит кончился». Владелец/со-владельцы
  не тарифицируются никогда; при бесплатном слоте ($0) списания нет.

**Как это реально работает (middleware платного гейта):**
- Гость без баланса блокируется и видит твой текст + кнопки оплаты.
- Новичку показывается текст «при входе», тому, у кого баланс кончился —
  текст «лимит кончился».
- Владелец/со-владельцы и сами платёжные апдейты всегда проходят.

**⭐ Звёзды** — рабочий нативный платёж (инвойс XTR + pre-checkout +
зачисление баланса). **Возврат:** команда владельца `/pm_refund <user_id>`
вернёт последнюю оплату звёздами (как требует Telegram).

**💳 Карта** — два режима. Без токена это ручной перевод по реквизитам. Если
владелец задал **provider-токен** (BotFather → Payments → ЮKassa/Stripe) и
валюту, бот шлёт настоящий инвойс Visa/Mastercard прямо в Telegram и зачисляет
баланс автоматически после оплаты.

**🪙 Крипта** — аналогично. Без токена — ручной перевод по адресу. С токеном
**CryptoBot (Crypto Pay)** бот выставляет крипто-инвойс; зачисление —
мгновенное через вебхук (если задан публичный URL) либо по проверке инвойса.
Леджер оплаченных инвойсов защищает от двойного зачисления.

## 6. 📣 Оповещения

**Путь:** `… → 🔒 Приват режим → 📣 Оповещения`.

- **Текст при входе** — что видит новый гость (под ним кнопки оплаты).
- **Текст когда лимит кончился** — что видит гость с нулевым балансом
  (тоже с кнопками оплаты).

## Реализовано в этой версии

- ✅ **Точечный доступ для гостей**: «Функции» (USE) теперь действительно
  блокируют конкретные функции, а «Что они видят» (SEE) прячут их кнопки в
  меню — через `bot/feature_gate.py` (middleware + фильтр меню), а не только
  общий платный гейт.
- ✅ **Авто-оплата картой и криптой**: provider-токен (ЮKassa/Stripe) для карты
  и CryptoBot для крипты с мгновенным вебхуком; звёзды как и раньше.
- ✅ **Потокенное списание**: баланс гостя расходуется пропорционально
  использованным токенам (`🎟 Токенов на 1 слот`), а не «пока баланс > 0».

## Что honest НЕ доделано (на будущее)

- Реестр функций (`FEATURE_CALLBACK_PREFIXES`) покрывает все 15 функций по их
  основным callback-префиксам и командам. Если у функции появится новый
  редкий callback-префикс — его нужно добавить в реестр, иначе USE-гейт его
  не распознает (по умолчанию незнакомый апдейт пропускается — fail-open).
- Точность стоимости токена зависит от настройки `🎟 Токенов на 1 слот`:
  это единый курс на всю модель, а не подтягивание реальных цен каждого
  провайдера по-отдельности.
