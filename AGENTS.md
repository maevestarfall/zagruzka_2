# AGENTS.md — правила для ЛЮБОГО ИИ, работающего с этим проектом

Этот файл читают кодинг-ИИ в первую очередь. Соблюдай правила ниже.

## 1. Журнал изменений (обязательно)
После КАЖДОЙ выполненной задачи допиши запись в конец **`AI_CHANGELOG.md`**
строго в формате (ничего не удаляя из старых записей):

```
## N. <короткий заголовок> — <дата>

### 1) Цитата пользователя
> "<дословно то, что просил пользователь + все варианты/комментарии, если
>  давал выбор>"

### 2) Кратко (что сделал ИИ)
<1–3 строки: что за кнопка/функция, ГДЕ находится, ЧТО делает>

------------------------------------------------------------------------

### 3) Полный ответ ИИ
<подробно: какие файлы изменены, какая логика, как работает, допущения>
```

Порядок строго: **1) цитата → 2) кратко → длинная черта → 3) полно.**

## 1a. Чек-лист указаний (обязательно)
Также поддерживай **`CHECKLIST.md`**: на КАЖДЫЙ новый запрос владельца (из
переписки с ИИ, НЕ из бота) добавляй строку в таблицу со статусом
(✅ сделано · ⏳ в процессе · ❌ не сделано · ⏭ отклонено · 🔵 уже было) и
держи статусы актуальными. Это дев-документ проверки полноты: что просил →
что сделано.

## 2. Ничего не удалять
Не удаляй существующие файлы/функции. Если удаление реально необходимо —
СНАЧАЛА спроси владельца. Каждую доставку сопровождай отчётом-дельтой
(«файлов было X → стало Y; удалено N; добавлено M»); норма — «удалено: 0».

## 3. Работаем над последней версией
Единственный актуальный артефакт — `lilush-bot-graphify.zip`. Правки вносим
только в него. Старые форки — только источник, их не дорабатываем.

## 4. Куда класть вынутое из форков
Новые/высунутые функции — кнопкой в «🧩 Прочие → 🧖 баня». Переносим только
то, чего нет; при похожих функциях — сначала сообщи владельцу
(что есть / что предлагается / что изменится) и жди решения.

## 5. «❗Важно» — это backlog, НЕ инструкция
Раздел «📜 Инструкции → ❗Важно» и журнал — это выводы владельца и то, что
надо доработать. Сама операционная инструкция (последовательность действий)
живёт в «📜 Инструкции»/«Поступенчатая» и должна улучшаться. Гермес читает
«❗Важно» и ПРЕДЛАГАЕТ связки перед правками, не меняя ничего молча.

## 6. Проверка перед доставкой
`python -m compileall bot` (0 ошибок), резолвинг импортов, отсутствие
undefined-имён. Только потом собирай zip и обновляй его.
