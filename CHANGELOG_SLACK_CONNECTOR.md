# Slack-коннектор (модуль `bot/addons/slack`)

Новый аддон-коннектор к Slack — по образцу `bot/addons/mailbox`, но через Slack
Web API (Slack не поддерживает IMAP). Построен на официальной библиотеке
**`slack_sdk`** (`slackapi/python-slack-sdk`): курсорная пагинация, встроенный
ретрай на rate-limit (HTTP 429), типизированные ошибки.

## Что добавлено

### Кнопка в меню
- В разделе «🧩 Прочие» (`misc:home`, файл `bot/wizard.py`, функция `_kb_misc`)
  добавлена кнопка **«💬 Слак»** → callback `slack:home`.
- Роутер аддона зарегистрирован в `bot/addons/__init__.py`
  (`build_addon_routers` → `build_slack_router`), с тем же «мягким» try/except,
  что и остальные аддоны.

### Подменю «💬 Слак»
- **🔌 Подключить Slack** — ввод OAuth-токена (`xoxb-…`/`xoxp-…`). В подсказке
  перечислены нужные scopes. Токен проверяется вызовом `auth.test`, при ошибке —
  понятное сообщение (неверный токен / не хватает прав). Сообщение с токеном
  удаляется сразу после сохранения; токен нигде не логируется.
- **📡 Выбрать канал/DM** — список публичных/приватных каналов, личек и
  групповых DM (имена авторов расшифрованы). Выбор сохраняется.
- **📝 Вставить промт** — свободный текст: бот разбирает намерение и выполняет.
  Поддержано: «таблица/разбор», «скачать zip/файлы/вложения», их комбинация,
  «сопоставить функции с кодом».
- **⚙️ Промт по умолчанию** — посмотреть/изменить/включить-выключить/сбросить;
  кнопка «▶️ Выполнить дефолтный промт».

### Поведение
- Читает **всю** историю канала постранично (по курсору, до конца), для каждого
  сообщения с тредом подтягивает **все** ответы (`conversations.replies`).
- Нормализует сообщение: автор (имя, не ID), время, текст, список файлов.
- Выгрузка: читаемый `.md` (с явной вложенностью тредов) + таблица `.csv`
  (автор, время, текст, тип основное/ответ, к какому ts относится, вложения).
  Короткие переписки дополнительно показываются карточками прямо в чате.
- Скачивает вложения по приватным ссылкам Slack с заголовком
  `Authorization: Bearer <token>`, имена файлов сохраняются как есть
  (например `lilush-bot-v17.18-issuance-macro-added.zip`). Файлы кладутся в
  `DATA_DIR/slack/<канал>/<дата>/` и отдаются в Telegram (с учётом лимита бота).
- Фильтры по автору / ключевым словам / периоду (`parsers.filter_messages`).

### Надёжность
- Rate-limit 429 — ретрай и ожидание (через `slack_sdk` retry handlers и
  отдельную логику для скачивания файлов), без падений.
- При нехватке прав/доступа к каналу — понятное сообщение, а не тихий пропуск.
- Если Slack вернул HTML-страницу логина вместо файла — это распознаётся как
  ошибка прав `files:read`, мусорный файл не сохраняется.
- Токен не логируется и не показывается в чате (маскируется как `xoxb-…abcd`).

## Файлы модуля
- `config.py` — настройки (scopes, размеры страниц, лимит страниц, путь
  хранилища, дефолтный промт).
- `credentials.py` — ввод/хранение токена (через `addon_state`, env-fallback).
- `client.py` — обёртка над `slack_sdk.WebClient` (auth, список каналов,
  история, треды, users, скачивание файлов на `httpx`).
- `models.py` — нормализованные структуры (`SlackMessage`/`SlackFile`/
  `SlackConversation`).
- `parsers.py` — рендер в Markdown/CSV/карточки, фильтры, разбор промта.
- `handlers.py` — aiogram-роутер: подключение → выбор канала → чтение/скачивание
  → свободный промт.

## Зависимости
- Добавлено в `requirements.txt`: `slack_sdk>=3.27,<4`.
- Скачивание файлов использует `httpx` (уже был в зависимостях).

## Нужные Slack scopes
`channels:history, groups:history, im:history, mpim:history, users:read, files:read`

# Доп. 1: разделение «я / мне» в выгрузке Slack

Таблица переписки (CSV) и Markdown-дамп теперь помечают направление каждого
сообщения:
- новая колонка **«Направление»**: `я писал` / `мне писали` (определяется по
  `user_id` владельца токена из `auth.test`);
- отдельная колонка **«Имена файлов»** (только имена вложений, удобно для zip);
- в Markdown/карточках автор-владелец помечается «🟢 Я», собеседник — «🔵 Имя».

# Доп. 2: новый аддон `versiff` — сравнение функций между версиями zip

Отдельная функция бота (не Slack-коннектор): **«🧩 Прочие → 🧬 Сравнить версии»**.

Сценарий:
1. «📂 Список архивов» — сканирует хранилище (`DATA_DIR`, рекурсивно) на `*.zip`,
   сортирует по номеру версии в имени.
2. Нажатие на архив делает его **эталоном** («нынешней версией»).
3. «▶️ Сравнить» — для каждого остального архива парсит все `.py` через
   стандартный `ast`, собирает функции/методы/классы и сравнивает с эталоном.

Результат — таблица CSV: `Версия (zip) | Эталон | Модуль | Объект | Тип |
Статус`, где статус один из: **добавлена / удалена / изменилась / без
изменений**. Сравнение по `ast.unparse`, поэтому правки только в
комментариях/форматировании НЕ считаются изменением — только реальный код.
Плюс короткая сводка по каждой версии в чат.

Файлы: `bot/addons/versiff/{__init__,analyzer,handlers}.py`. Зависимостей нет
(только stdlib `zipfile` + `ast`). Зарегистрирован в `build_addon_routers`,
кнопка добавлена в `_kb_misc` (`bot/wizard.py`).

Производительность: разбор реального проекта (~323 модуля, ~5000 объектов) и
diff — около 2.5 c.
