# Changelog — Приват-режим: реальное применение тогглов + потокенная оплата

Этот релиз закрывает два места, где приват-режим был только «нарисован», но
не работал по-настоящему. Всё остальное (20 слотов, авто-переключение, бюджет
токенов, «во все 20 слотов», верхний выбор модели, flush-verify перед
переключением, оплата карта/звёзды/крипта с тогглами и оповещениями) уже было
реализовано и **не трогалось**.

## 1. «Функции» и «Что они видят» теперь действительно работают

Раньше тогглы `guest_can_use` / `guest_can_see` существовали и были покрыты
тестами, но **ни один обработчик их не спрашивал** — кнопки были косметикой.
Гость, прошедший платный гейт, мог использовать и видеть всё.

- **Новый модуль `bot/feature_gate.py`** — единый реестр:
  - `FEATURE_CALLBACK_PREFIXES` / `FEATURE_COMMANDS` — какие callback-префиксы и
    команды открывают каждую из 15 функций (проверяется на соответствие
    `private_mode.FEATURE_KEYS` при импорте, чтобы реестр не «уплыл»).
  - `MENU_BUTTON_FEATURE` — какие кнопки меню к какой функции относятся.
  - `build_feature_use_gate_middleware()` — **USE-гейт**: внешняя middleware,
    которая для гостя определяет функцию по апдейту и блокирует с алертом, если
    у неё не стоит ✅ в «Функциях».
  - `filter_menu_rows()` — **SEE-фильтр**: убирает из меню кнопки функций без ✅
    в «Что они видят».
- **`bot/main.py`** — USE-гейт регистрируется сразу **после** платного гейта.
- **`bot/wizard.py`** — `filter_menu_rows()` применён к главному меню
  (`_kb_main_after_claim`) и к «Настройкам» (`_kb_settings_menu`).

Гарантии: владелец/со-владельцы проходят всегда; обычный чат и админ-экраны
не трогаются; при выключенном приват-режиме оба слоя — no-op (бот ведёт себя
как раньше); оба слоя «fail-open» (ошибка внутри не ломает обработку апдейта).

## 2. Потокенное списание баланса («на сколько оплатил — на столько и пользуется»)

Раньше `pm_deduct_balance` вызывался только при возврате — баланс **никогда не
уменьшался от использования**. Один раз оплатил — пользуешься вечно.

- **`bot/private_mode.py`** — `tokens_per_slot` (по умолчанию 1 000 000),
  `usd_per_token()` = `usd_per_slot / tokens_per_slot`, `meter_tokens()` —
  чистое списание из баланса по числу токенов (никогда не уходит в минус,
  не падает на мусорном вводе; при бесплатном слоте $0 списания нет).
- **`bot/storage.py`** — `pm_set/get_tokens_per_slot`, `pm_meter_guest_usage()`
  (no-op, если приват выключен, нет платного метода, или это владелец).
- **`bot/agent.py`** — `user_id` проброшен в `_call_model_with_failover` →
  `_call_model_for_slot`; после каждого ответа модели баланс гостя списывается
  на `prompt+completion` токены. Когда баланс доходит до 0 — платный гейт сам
  показывает «лимит кончился».
- **UI:** в «💰 Оплата» добавлена кнопка **🎟 Токенов на 1 слот** и строка
  «$X = 1 слот ≈ N токенов».

## 3. Тесты

- `tests/test_feature_gate.py` — реестр, разрешение функции по callback/команде,
  USE-гейт (off/блок/разрешение/владелец/неизвестное/нужен баланс),
  SEE-фильтр (off/скрытие/видимость/владелец).
- `tests/test_pm_metering.py` — математика списания, клампы, исключения,
  бесплатный слот, и гардинг storage-обёртки (off / без метода / владелец /
  списание + сохранение на диск).
- `tests/test_agent_cancel.py` — фейки модели обновлены под новый kwarg `user_id`.

Все целевые наборы (`test_feature_gate`, `test_pm_metering`, `test_private_mode`,
`test_access`, `test_brain_*`, `test_agent_*`) — зелёные.
